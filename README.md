# RestoCore POS · Velyon Apps

El sistema de tu restaurante, gratis para empezar: salón con mesas, comandas a cocina, precuenta, cobro por mesa y cierre de caja. Plan gratis sin vencimiento hasta S/ 8,000 de ventas al mes. Con el plan Pro, boletas y facturas electrónicas SUNAT con el IGV reducido de restaurantes. Funciona sin internet.

- **Página y planes:** https://velyonapps.github.io/restocore/
- **Descargar (Windows 10 u 11):** [VelyonRestoCore-win-Setup.exe](https://github.com/velyonapps/restocore/releases/latest/download/VelyonRestoCore-win-Setup.exe)
- **Sugerencias y errores:** velyonapps@gmail.com
- **Plan Pro:** desde la app (Gestión → Mi plan) o escribiendo a velyonapps@gmail.com

¿Tienes una bodega o minimarket? Ese es otro producto: [RetailCore POS](https://velyonapps.github.io/retailcore/).

Este repositorio solo publica la página y los instaladores oficiales. Cada versión indica la huella SHA-256 de su instalador.
